    Keep Fennec close.

    1. iPhone / iPad: open in Safari, tap Share, then Add to Home Screen (look under More if needed).
    2. Android: in a supporting browser such as Chrome, choose Install app or Add to Home screen from the menu.
    3. Windows / Linux / macOS: use your supporting browser's Install app option. Safari on recent macOS offers Add to Dock. Availability varies by browser.

    The installed shell can open offline. Chat, agent execution, and file access still need your server; the local engine starts on demand when you send a message.
