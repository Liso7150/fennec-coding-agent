browser PWA it serves.

### Added
- A Rust/Axum web backend replacing the Node.js/Electron front end: the
  `fennec-agent` binary from `src/main.rs` binds `127.0.0.1:8787` (falling back to
  `:8788` when the shared agent loop owns the port, or to `FENNEC_AGENT_ADDR` when
  set) and serves `/health`, `/api/capabilities`, `/api/models`, `/api/tasks` (+ `/:id`,
  `/start`, `/stop`, `/messages`), `/api/agents`, `/api/agents/:id/delegate`,
  `/api/repositories` (+ `/:id`, `/status`), `/api/outlets`, `/api/stt`,
  `/api/work/files`, `/api/work/file`, `/api/browse`, `/api/events` as SSE and
  `/api/events/ws`, with `web/` served statically
- Modules behind those routes: `src/task.rs`, `src/agent.rs`, `src/repository.rs`,
  `src/github.rs` (the `gh`-backed GitHub binding: list, create, link),
  `src/obsidian.rs`, `src/browser.rs`, `src/work.rs`, `src/ag_ui.rs` (AG-UI /
  CopilotKit run endpoint over SSE) and the event bus in `src/events.rs`
- Two extra binaries: `fennec-nod` (MCP entry point) and `fennec-antigravity`
  (optional outlet), each exposed in the PWA
- Standalone browser PWA: redesigned `web/index.html` and `web/styles.css`, plus
  `web/app.js` — button handlers, warm-dark three-pane layout, task-queue logic,
  workspaces, theme presets, permission-mode dropdown, unified composer/model
  dropdowns, real STT and per-message TTS
- Queue contract: two visible rows with scrolling; AI-added rows are first and locked,
  while user-added rows can be edited, removed and reordered
- Turn rendering matched to the desktop: one running block per stretch between
  answers, tool rows folded to a basename or seven words, answered approvals in My
  Attention, fenced code as cards, written files as attachments opening in the right
  panel
- Self-destructing `web/service-worker.js`: the old worker answered versioned script
  URLs from cache, so a returning browser got the previous app forever. The
  replacement claims the scope once, unregisters itself and never caches
- Backend test coverage (Rust lane, 70 passing): events, updater, task, agent,
  repository modules — serialization round-trips, ID generation, enum variants, struct
  defaults — plus `src/work.rs`
- PWA contract coverage (42 passing in the hub's PWA lane): `web/tests/assets.test.mjs`
  and `web/tests/progress.test.mjs` hold the DOM and asset contracts
- `src/updater.rs`: checks `Liso7150/fennec-coding-agent` GitHub releases, with an
  experimental path that reads the branch commit

### Changed
- Crate is Rust edition 2024 with `rust-version = 1.85`; dependencies include axum 0.7
  (ws), tokio, tower-http (fs/cors/trace) and the sibling crates `fennec-client` and
  `fennec-workspace-tools` from `../fennec-core/src/`
- The Rust agent is canonical for web tasks: the `web_task` tool runs under the Fennec
  identity, and the browser lane is Fennec's own loop decided one step at a time by a
  Liquid **d1** model (hosted `d1.2` via `LIQUID_API_KEY`, or open-weight `d1-2B` via
  `LIQUID_ENDPOINT`)
- The model chip names the checkpoint the engine actually holds. Fennec serves one
  model and answers every request as it, so the PWA asks `/api/models` (which proxies
  the engine's own `/health` id) and only a served id may settle the choice; a stored
  pick the engine isn't running is replaced rather than displayed. An unreachable
  engine yields an empty list and the fallback menu stands.
- Failed sends stay visible, plain-text message content serializes correctly on the
  SSE wire, and experimental updates check the right branch instead of a stale one
- Task list, timeline header and search render dynamically; context inspector stays
  reachable at narrow widths
- Fox mark replaces the shield icon; README rewritten for the Axum backend

### Removed
- The JavaScript-only front end that briefly replaced it: `web/helpers.js` and
  `web/updater.js` are gone, their behaviour folded into the Rust backend and the new
  `web/app.js`
- The GPUI application module `src/app.rs` and the old `src/api.rs`, superseded by the
  Axum main
- The optional `gui` feature and its GUI binary (2026-11-21): the suite ships one
  native window, the gpui shell in `fennec-desktop`, and every capability only that
  binary had was ported into it first. This repo is the Axum backend and the PWA the
  browser opens; the `gpui-kit`, `fennec-ui`, `cpal`, `hound` and `base64` dependencies
  went with it
- The deleted third-party browser outlet's agent identity: the events envelope has no
  reason to name an outlet that is not installed
